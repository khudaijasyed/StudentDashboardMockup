HacktoberFest Hackathon 2026 (Team A)

Student Space, a responsive AI-powered student dashboard designed with students at its core, aiming to simplify everyday academic life by 
bringing essential tools and resources into one convenient, personalised space. 
Instead of juggling multiple tabs and apps, students can access Outlook, manage their university and personal timetables, organise study notes, and track deadlines alongside personal commitments. Additionally , It is Integrated with AI tools to help students generate notes, create to-do lists, and quiz themselves to support more effective studying

To try the dashboard yourself please follow this link! : https://khudaijasyed.github.io/StudentDashboardMockup
For Gemma AI Integration , user needs to enter their own generated API key for security and ethical regulations
Generate keys using : aistudio.google.com/api-keys 

Tools and Resources used: HTML, CSS, JavaScript, TypeScript, Figma Ai, Claude, Google Gemini API (Gemma), validated AI-driven actions, persistent browser storage, and GitHub Pages deployment.
